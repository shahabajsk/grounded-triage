# Synthetic data

Generated by `python -m grounded_triage.synth --out data --seed 42`. Every name, id, merchant and amount is invented.

- `ledger.json`: customers, merchants, transactions and delivery records. The agent reads these through `ledger.py` only.
- `cases.json`: 60 disputes with the expected category and action, across 10 scenarios. Three scenarios are hard cases the offline model is expected to miss; see LIMITATIONS.md.

Regenerating with the same seed gives identical files. A different seed gives a different mix, and the pinned baseline test will fail until the README table is updated.
